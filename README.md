# 唤译 Huanyi

随叫随到的 Windows AI 翻译助手。常驻系统托盘，支持鼠标划词按钮、就近译文浮窗，以及 **Ctrl + Alt + S** 框选截图后直接上传模型识字翻译。原有 **Ctrl + Alt + D** 选中即译和 **Ctrl + Alt + T** 唤窗继续保留。

## 怎么用

1. 启动唤译，点击右上角齿轮，填写模型服务的 API 地址、模型名称和 API Key。
2. 在其他软件中选中文字，按 **Ctrl + Alt + D**，浮窗会自动弹出并开始翻译，无需先复制。
3. 如果软件不支持选区复制，也可以 **Ctrl + C**，再按 **Ctrl + Alt + T** 唤出；普通唤窗只读取剪贴板，不自动发送。
4. 可以选择目标语言、风格、表达态度和力度后再翻译；选中即译沿用浮窗当前的选项。
5. 点击“复制译文”，返回原来的软件粘贴。
6. 按 **Esc** 或右上角关闭按钮收起。程序仍在托盘运行；右键托盘可彻底退出。

首次启动会显示空白浮窗，不读取剪贴板。选中即译仅在主动按 Ctrl + Alt + D 时发送选中文字；未配置模型时先打开设置，不发起请求。只有快捷键唤出、托盘点击、再次打开程序，或主动点击“读取剪贴板”时才读取文字。正在翻译时不会用新剪贴板覆盖原文。收起浮窗会停止当前模型请求。

## 鼠标划词与截图翻译（0.4.1）

### 鼠标划词

- 在其他软件中用文字光标（I 形光标）拖动选择或双击文字，附近先显示「译 · 翻译」候选按钮，不必等无障碍取词成功。非标准光标下，需要无障碍接口确认选区后才显示；按钮不主动取得键盘焦点。
- 点击按钮才把本次选区发送给当前模型，并在选区附近打开紧凑译文浮窗；沿用当前目标语言、风格、态度和力度。点击「展开」可返回完整工作台。
- 默认开启，可在设置或托盘菜单关闭「鼠标划词按钮」，开关独立保存，不要求填写 API Key。
- 划词时先尝试 Windows UI Automation，本机读取、不发送模型、不动剪贴板。点击按钮后，如果仍无法取得无障碍文字，会调用与 Ctrl + Alt + D 相同的 Ctrl + C 取词/剪贴板恢复流程；仅在确认取得本次新选区后才翻译。
- 复制回退会临时使用剪贴板，可能被系统剪贴板历史/第三方工具记录。仅恢复当前剪贴板，不能清除这些历史记录。若期间出现新的复制内容，不覆盖它。
- 文字光标手势只能表示“可能选中了文字”，不能保证确有选区；无文字、无法复制或选区过期会提示失败，不把旧剪贴板当作选区发送。
- 按 Esc、点击其他位置、切换窗口或等待约 12 秒会关闭按钮。点击期间若原窗口切换或操作取消，不会向新窗口发送复制快捷键。管理员权限窗口、复制受限软件、非标准光标、自绘界面及部分游戏仍可能无法划词，可使用截图翻译。
- 识别到密码控件时跳过。无障碍取词依赖目标软件正确提供选区，使用前仍应留意选中的内容。

### 截图直接上传翻译

1. 先配置一个**支持图片输入**的模型。沿用现有 API 地址、模型和 API Key，不需要另外安装本机 OCR。
2. 按 **Ctrl + Alt + S**，或点击右上角截图按钮、托盘「截图翻译」。
3. 在鼠标所在屏幕拖动框选；界面明确显示「框选后直接上传并翻译」及当前模型。
4. **松开鼠标完成框选后，所选区域立即上传到当前模型**，由模型识字并翻译。不是先做本机 OCR，也不需要再点一次确认。
5. 附近浮窗显示截图原文缩略图和流式译文，可停止、复制、切换态度，或展开工作台修订。修订及态度切换会重新发送原截图。

边界：
- 框选前按 Esc、右键、取消或切换窗口可取消，不发送图片。开始请求后停止只能中断后续传输/生成，不能撤回服务商已经收到的数据。
- 只上传裁剪后的选区，不上传未选中的屏幕区域。截图不写入历史、不复制到系统剪贴板；当前截图在内存中保留以便重试/修订，清空或换成文字即可移除。
- 当前一次框选限制在鼠标所在的单个显示器，支持按实际截图比例处理缩放；不支持跨屏拖动。图片最长边缩至 4096 像素，PNG 上限 8 MB，超限需缩小选区。
- 接口须支持 Chat Completions 的 `image_url` 图片内容，包括内嵌 PNG 数据。纯文本模型无法截图翻译；服务拒绝图片时会提示更换支持图片的模型/接口。
- 受保护或黑屏内容无法保证捕获。识字与翻译质量取决于所用视觉模型，重要内容应核对。

## 选中即译的行为与限制

- **Ctrl + Alt + D** 会等待你松开快捷键，向当前前台软件发送一次 Ctrl + C，确认取得本次选区的新文字后才提交翻译。
- 取词过程中暂借系统剪贴板，尝试恢复原来的文字、HTML、图片等可读写格式；若检测到其他软件/用户写入新内容，不会覆盖其新剪贴板。
- 没有选区、没有复制到文字、窗口切换、超出 24,000 字符，都会提示失败，不会把旧剪贴板内容拿去翻译。
- 翻译进行中重复按快捷键不会覆盖当前原文、重新提交或停止现有请求。
- 取词依赖软件支持 Ctrl + C。管理员权限窗口、游戏、自绘界面、复制受限内容及密码框可能无法获取，仍可使用手动复制流程。
- 不安装键盘监听钩子，也不持续抓取选区。这个快捷键代表“获取选区并发送给已配置模型”的主动操作。
- 临时复制可能被 Windows 剪贴板历史或第三方剪贴板工具记录；恢复当前剪贴板不等于删除其他工具记录。

## 带态度的翻译

译文下方的 **表达态度** 和顶部的 **翻译风格** 相互独立：风格控制自然、忠实或正式，态度控制说话的口吻。

- 常用：**原味、友好、讨好、严肃、坚定**。
- 更多态度：**委婉、撒娇、高冷、俏皮、阴阳怪气**。每种态度都有简短说明；反讽可能被误解，请谨慎使用。
- 非原味可调 **一点点 / 明显 / 拉满** 三级力度。原味保留原文语气，力度不生效。
- 未翻译时只选择参数，不发送文字；已有有效译文时，切换态度或确认力度会发起一次模型请求（可能产生服务商费用）。滑块拖动过程只预览力度，松开后才提交。
- 切换态度从原文重新生成，不在旧译文上反复改写。译文标题旁显示实际生成这版译文的态度和力度。
- 如果原文、语言或风格已变，切换态度不会自动发送新内容，需点击“开始翻译”。
- 切换失败或停止会保留上一版成功译文；若上一版不匹配当前选项，会提示重新翻译，并暂时禁用修订。
- 翻译或修订过程中锁定态度选项；原有修订功能会带上当前态度与力度。
- 态度仅在当前会话中保留，重启恢复原味；选中即译会使用当前态度，请在发送前确认。

提示词明确约束：只调表达，不改变事实、立场、承诺、否定、时间或条件；不凭空加赞美、道歉、感谢、保证或威胁。例如“我今天做不完”不能被改成“我一定加班完成”。这些是对模型的约束，不是对每次输出的绝对保证，重要沟通仍需核对译文。

## 已实现

- 系统托盘常驻、三组全局快捷键、单实例、可选窗口置顶。
- 鼠标划词按钮、选区附近紧凑浮窗、可持久关闭的鼠标划词开关。
- 框选截图后直接上传视觉模型识字翻译、截图预览、停止/重试/态度重译。
- Windows 当前前台软件选区获取、快捷键一键自动翻译、剪贴板恢复及失败保护。
- 原文 / 译文双栏、流式输出、可停止的模型请求。
- 自动中英互译，以及中文、英语、日语、韩语、法语、德语、西班牙语目标。
- 自然、忠实、正式三种翻译风格；十种表达态度与三级力度。
- 保持原文依据的修订：更自然 / 更正式 / 更简洁 / 自定义要求。
- 修改失败保留此前成功译文；原文或选项变化后必须重新翻译才能修订。
- API Key 系统加密存储，不在界面回显已保存的密钥。

## 模型连接

使用 **兼容 Chat Completions** 的接口，发送 `POST {基础地址}/chat/completions`，支持 SSE 流式与标准 JSON 回包。基础地址通常以 `/v1` 结尾，也可填写完整 `/chat/completions` 路径。

- 远程地址要求 HTTPS，本机 `localhost`、`127.0.0.1`、`[::1]` 可使用 HTTP。
- 模型 ID 必须使用服务商实际提供的名称，软件不替你猜测可用模型。
- 第一版要求填写 API Key；无鉴权本机服务可填其接受的非空占位值。
- 部分服务不兼容此协议、系统提示词或流式参数，需要单独适配。
- 单次原文最多 24,000 字符，单次请求超时 90 秒。
- 只有主动发起翻译、修订，或对已有有效译文切换态度/力度时才调用模型。修订会发送原文、当前译文、修改要求；态度切换仅以原文重新生成。

## 隐私与边界

- 不在后台轮询剪贴板；只在选中即译期间短暂检查剪贴板更新。不自动提交普通复制的内容，不保存翻译历史。
- 截图、原文、译文只保留在应用内存；系统剪贴板、系统交换文件和模型服务商不受本应用控制。
- API Key 保存在用户配置目录的 `settings.json` 中，使用 Electron safeStorage 的系统加密能力。安全存储不可用时拒绝保存密钥，不退回明文。
- 远程 API 会收到你的 API Key 和翻译内容（截图模式包括裁剪图片），请只填写可信服务地址。服务商是否留存内容需查看其自身政策。
- 渲染界面启用沙箱与 context isolation，不能直接访问 Node.js、发起网络请求或打开外部页面。模型回包作为纯文本显示，不解释成 HTML。
- 翻译流程不强制执行“理解 → 翻译 → 审校”三次模型调用；第一版使用一次上下文感知翻译，后续由用户决定是否修订。

## 运行打包版本

- 便携版：双击 `dist/Huanyi-0.4.1-x64.exe`，不需要另装 Node.js。
- 文件夹版：运行 `dist/win-unpacked/Huanyi.exe`，请保留同目录全部文件，不要只移动这个 exe。
- 当前版本未做代码签名，正式分发前应补充签名与发布流程。
- 软件不内置 API Key；启动后必须使用自己的模型配置。无需把密钥发给开发者。
- 升级前在托盘退出旧版，再启动新版；只关闭窗口不会退出。仍运行旧版时，新 exe 会被单实例机制拦回旧窗口。旧版模型设置可沿用。

## 开发

要求 Node.js 22.12+、Windows 10/11 x64。

```powershell
npm install
npm start
```

如果当前终端继承了 `ELECTRON_RUN_AS_NODE=1`，启动前在当前会话移除它：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm start
```

## 测试与打包

不弹窗的后台检查/打包：

```powershell
npm test              # Node 单元测试；主进程/截图采用模拟适配器，不调用真实桌面
npm run test:headless # 强制无窗口浏览器 UI 测试；不读取真实剪贴板、不截图桌面、不操作系统输入
npm run pack          # 生成 Windows 文件夹版，不启动
npm run dist          # 生成 Windows x64 便携版，不启动
npm run test:package # 静态核对 app.asar、原生辅助文件和 EXE 版本，不运行 EXE
```

`test:headless` 优先使用本机 Chrome 的 headless 模式，否则使用已安装的 Playwright Chromium；不自动切换为可见浏览器。

**以下测试会弹窗/抢焦点，必须征得当前用户明确同意后才能运行。默认直接拒绝执行：**

```powershell
# 只在用户允许桌面交互测试的时间段设置：
$env:HUANYI_ALLOW_DESKTOP_TESTS = '1'
npm run test:desktop     # 真实 Electron UI 与本机模拟模型服务
npm run test:selection   # 实际 Windows 快捷键、剪贴板和外部软件选区
npm run test:interaction # 实际鼠标划词、按钮点击、真实屏幕裁剪和模拟视觉模型请求
npm run test:portable    # 启动便携 EXE
Remove-Item Env:HUANYI_ALLOW_DESKTOP_TESTS
```

交互测试使用独立配置目录，不修改正式模型配置；部分测试会占用快捷键、鼠标、焦点或剪贴板。不要在游戏、会议、工作期间运行。测试产物和日志在 `.test-artifacts/`，不随便携包分发。
